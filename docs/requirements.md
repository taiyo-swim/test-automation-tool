# E2E Test Automation Tool - 要件定義書

## 1. プロダクト概要

Web・モバイルアプリ対応のE2Eテスト自動化ツール。ノーコード操作・AI支援・セルフヒーリングを備え、開発チーム全員がテストを作成・管理できるクラウドベースのプラットフォーム。

---

## 2. 対象ユーザー

| ユーザー種別 | 説明 |
|---|---|
| QAエンジニア | テストの設計・管理を担当 |
| 開発者 | CI/CDパイプラインへの組み込み、コードベーステスト |
| 非エンジニア (PM/デザイナー) | ノーコードUIでテスト作成 |
| DevOps/SRE | インフラ管理・実行環境の運用 |

---

## 3. 機能要件

### 3.1 テスト対象プラットフォーム

#### Web
- ブラウザ: Chrome / Firefox / Safari / Edge
- ヘッドレスモード対応
- レスポンシブデザイン (viewport設定)
- iframeサポート
- Shadow DOM対応

#### モバイル
- iOS (実機 / シミュレータ)
- Android (実機 / エミュレータ)
- Flutter アプリ
- React Native アプリ
- モバイルブラウザ (Webview含む)

#### API
- REST API テスト (HTTP/HTTPS)
- GraphQL テスト
- 認証 (Bearer Token / OAuth2 / API Key / Basic Auth)
- レスポンスアサーション (ステータスコード / JSON / Headers)

---

### 3.2 テスト作成

#### 3.2.1 ノーコード (GUI ステップエディタ)
- 160+ の操作コマンド
  - UI操作: クリック, 入力, スクロール, スワイプ, ドラッグ&ドロップ, 長押し, ピンチ
  - アサーション: テキスト確認, 要素存在確認, 画面キャプチャ比較
  - 制御フロー: if/else, ループ, wait, 変数
  - データ操作: 日時計算, 四則演算, 正規表現, TOTP(二要素認証)
- CSVによるデータドリブンテスト
- 共有ステップ (ステップのモジュール化・再利用)

#### 3.2.2 レコード&プレイバック
- Chromeエクステンションによるブラウザ操作の自動記録
- モバイル: 画面ミラーリング + タップ操作の記録
- 記録したステップの編集・最適化

#### 3.2.3 AI支援 (Autopilot)
- 自然言語による指示からテストステップを自動生成
  - 例: 「ログインして商品を検索し、カートに追加する」
- 生成ステップのプレビューと編集
- 既存テストの自然言語による修正指示

#### 3.2.4 コードベース
- YAML/JSON形式のテスト定義ファイル
- Python / TypeScript SDK
- Playwright / Appium との連携API
- Gitリポジトリとの同期

---

### 3.3 AIセルフヒーリング

- UI変更 (セレクタ変更・テキスト変更) を自動検出
- 変更されたUI要素を自動で更新 (セルフヒーリング候補を提示)
- ユーザーが承認/拒否を選択できるワークフロー
- 意図ベースの修正 (ラベル名, 役割, 位置などの複合的な判定)
- ヒーリング履歴の管理

---

### 3.4 テスト実行

#### 実行モード
- クラウド実行 (マネージドインフラ、セットアップ不要)
- ローカル実行 (Docker Runner / CI環境)
- 並列実行 (複数ブラウザ/デバイスの同時実行)
- スケジュール実行 (Cron式で指定)
- CI/CDトリガー実行

#### 実行管理
- テストスイート (テストグループの管理)
- 実行優先度の設定
- タイムアウト設定
- リトライ設定 (失敗時の自動再実行回数)
- 実行環境変数の管理 (本番/ステージング/開発)

---

### 3.5 ビジュアルリグレッションテスト

- 画面全体/要素単位のスクリーンショット比較
- ピクセル差分の可視化 (diff画像)
- 差分閾値の設定 (許容誤差)
- ベースライン画像の管理・更新
- アニメーション/動的コンテンツの除外設定

---

### 3.6 レポート & 分析

#### テスト結果
- 実行ごとの詳細レポート (ステップ単位のpass/fail)
- 失敗ステップのスクリーンショット + 動画
- エラーログとスタックトレース
- 実行時間の計測

#### ダッシュボード
- プロジェクト全体のヘルススコア
- 合格率のトレンドグラフ
- 不安定なテスト (Flaky Test) の検出と一覧
- 実行時間の統計
- カバレッジサマリー

---

### 3.7 CI/CD インテグレーション

- GitHub Actions
- GitLab CI
- CircleCI
- Jenkins
- Bitbucket Pipelines
- Web API (汎用トリガー)
- Slack / Teams 通知 (実行結果)

---

### 3.8 チーム管理

- プロジェクト単位の管理
- ロールベースアクセス制御 (RBAC)
  - オーナー / 管理者 / 編集者 / 閲覧者
- ブランチ機能 (テストの安全な変更・レビュー)
- 変更履歴とバージョン管理
- コメント・レビュー機能

#### 認証
- メール/パスワード
- Google / GitHub OAuth
- SAML SSO (エンタープライズ)
- IPアドレス制限 (エンタープライズ)

---

## 4. 非機能要件

### パフォーマンス
- テスト実行開始レイテンシ: < 5秒
- 並列実行: プロジェクトあたり最大100並列
- ダッシュボード表示: < 2秒

### 可用性
- SLA: 99.9% (クラウド実行環境)
- メンテナンスウィンドウ: 月1回、深夜帯

### セキュリティ
- 通信: TLS 1.2以上
- データ暗号化: AES-256 (保存時)
- シークレット管理 (テスト用パスワード等の安全な保存)
- SOC2 Type II準拠 (エンタープライズ)

### スケーラビリティ
- テストスイート: 無制限
- 実行履歴: 90日間保存 (設定で延長可能)
- ストレージ: スクリーンショット・動画をオブジェクトストレージに保存
